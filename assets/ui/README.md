# TumanLake UI Assets

This folder holds reusable UI components for the premium mobile fishing interface.
The current pass recreates the visual direction with Godot resources and runtime styling instead of slicing reference images.

- `buttons/` primary, secondary, navigation, and icon-button style resources.
- `panels/` glass panels, cards, popup windows, and shop row surfaces.
- `hud/` compact HUD badges and progress widgets.
- `inventory/` slot and rarity frame resources.
- `icons/` future hand-painted icon assets.

Reference images are art direction only; no generated mockup text or sprite sheet is copied into the game.
