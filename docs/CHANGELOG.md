# Tuman Lake — Changelog

## Next beta / unreleased

### Исправлено
- Улучшена стабильность перегруза снасти во время вываживания.
- Удержание натяжения в зелёной зоне теперь корректно снижает риск накопления перегруза.
- Важные уведомления об обрыве/потере снасти теперь требуют явного подтверждения.
- Повторное случайное нажатие по кнопке действия больше не должно закрывать важное уведомление.
- Улучшена читаемость подробной карточки предмета в инвентаре.
- Исправлено переполнение правой панели подробной информации в инвентаре.
- Для предметов без собственной картинки добавлены fallback-иконки по категории.
- В магазине убрана пагинация во всех разделах.
- Магазин теперь использует прокрутку списка товаров вместо страниц.
- При смене категории магазина список начинается сверху.

### Что перепроверить
- Вываживание рыбы и поведение зелёной зоны.
- Обрывы лески/поводка/удочки.
- Popup после обрыва или потери снасти.
- Инвентарь на разных категориях предметов.
- Предметы без собственной картинки.
- Магазин: наживки, расходники, удочки, лески, поводки, крючки, поплавки.
- Покупку предметов после удаления пагинации.
- Кнопку “Подробнее” в магазине.
- Скролл магазина на 960x540 и на большом экране.

## v0.1.0-beta.1 — Closed Beta Cleanup
Дата: 2026-06-05

### Главное
- Проведена первая большая cleanup-подготовка проекта к закрытому бета-тесту.
- Основной рабочий водоём beta-версии: Озеро Агамим.
- Будущие водоёмы отображаются как контент в разработке и не открываются как рабочие локации.
- Добавлена версия билда для тестеров.
- Добавлена инструкция “Сообщить о баге” в системное меню.

### Cleanup
- Удалены лишние build-артефакты из Git.
- Удалена пустая сцена LakeScene.
- Удалён пустой autoload GameManager.
- Проверено отсутствие хвостов GameManager/LakeScene в tracked-файлах.
- Усилен .gitignore для локальных логов и временных файлов.

### Beta safety
- Отключён автоматический alpha tester bonus по умолчанию.
- Добавлен BuildConfig для beta/debug-флагов.
- Debug panel управляется через BuildConfig.
- Verbose-логи спрятаны за BuildConfig.ENABLE_VERBOSE_LOGS.
- Усилена загрузка сохранений после cleanup-контента.
- Старые/битые location-данные безопасно возвращаются на Озеро Агамим.

### Контент и совместимость
- Legacy-точки скрыты из активных списков.
- Legacy-покупатели скрыты из активных списков.
- Старые данные оставлены для совместимости сохранений.
- Недоделанные водоёмы не удалены, но защищены от выбора как рабочей локации.

### Документация
- Добавлен docs/BETA_CHECKLIST.md.
- Добавлен docs/TESTER_GUIDE.md.
- Добавлен docs/CHANGELOG.md.

### Что тестировать особенно внимательно
- Первый запуск новой игры.
- Загрузка старого save.
- Карта водоёмов.
- Выбор точек Агамима.
- Рыбалка и вываживание.
- Садок и продажа рыбы.
- Инвентарь и магазин.
- Системное меню.
- Кнопка “Сообщить о баге”.
- Сохранение после перезапуска.

### Известные ограничения beta scope
- Полноценно доступен только водоём Озеро Агамим.
- Онлайн, турниры, передача предметов и Google Play-интеграция не входят в текущий beta scope.
- Будущие водоёмы могут отображаться на карте, но не считаются готовым игровым контентом.
- Финальная графика и полный баланс ещё не считаются завершёнными.
