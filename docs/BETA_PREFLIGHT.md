# Рыбное Место — Beta Preflight

Этот чек-лист нужно пройти перед каждой сборкой beta-билда для тестеров. Для контентных коммитов без APK достаточно пройти Git, документацию и headless-запуск проекта; раздел APK/AAB выполняется только перед реальной сборкой.

## 1. Git

- [ ] Находимся на правильной ветке.
- [ ] Все нужные изменения закоммичены.
- [ ] `git status --short` пустой.
- [ ] Последний коммит соответствует текущему билду.
- [ ] Изменения отправлены на GitHub, если билд отдаётся тестерам.

Команды:

```bash
git status --short
git log --oneline -5
```

## 2. Версия билда

- [ ] Версия обновлена в `scripts/core/GameVersion.gd`.
- [ ] `VERSION` соответствует номеру beta-билда.
- [ ] `BUILD_NAME` соответствует названию билда.
- [ ] `BUILD_DATE` соответствует дате сборки.
- [ ] Версия видна в системном меню.

## 3. BuildConfig

- [ ] `IS_BETA_BUILD = true`.
- [ ] `ENABLE_ALPHA_TESTER_BONUS = false`.
- [ ] `ENABLE_DEBUG_PANEL = false`.
- [ ] `ENABLE_VERBOSE_LOGS = false`.
- [ ] `SPINNING_ENABLED = true`.
- [ ] `ENABLE_SPINNING_TEST_MODE = false`.

Файл:

```text
scripts/core/BuildConfig.gd
```

## 4. Запуск проекта

- [ ] Проект открывается в Godot 4.6.x.
- [ ] Игра запускается без `SCRIPT ERROR`.
- [ ] Intro корректно запускается или пропускается.
- [ ] Main-сцена загружается.
- [ ] Системное меню открывается.
- [ ] Кнопка “Сообщить о баге” открывает инструкцию.

## 5. Beta scope

- [ ] Новый игрок стартует на Озере Агамим.
- [ ] Точки ловли Агамима доступны.
- [ ] Legacy-точки не отображаются в активных списках.
- [ ] Будущие водоёмы не открываются как рабочие локации.
- [ ] Недоступный контент показывает понятное сообщение.

## 6. Smoke test

- [ ] Можно открыть карту.
- [ ] Можно открыть магазин.
- [ ] В магазине открываются вкладки “Удочки”, “Приманки” и “Катушки”.
- [ ] Спиннинговые удилища, наборы спиннинга и катушки показывают корректные цены, иконки и LVL-lock-и.
- [ ] Можно открыть инвентарь.
- [ ] Можно собрать снасть.
- [ ] Поплавочная снасть не требует катушку, спиннинг требует удилище, катушку и приманку.
- [ ] Катушка неподходящего размера даёт предупреждение/штрафы, а полностью сломанная неремонтируемая снасть удаляется из инвентаря.
- [ ] Можно сделать заброс.
- [ ] Поклёвка и подсечка работают.
- [ ] Вываживание запускается.
- [ ] Пойманная рыба попадает в садок.
- [ ] Продажа рыбы работает.
- [ ] Сохранение загружается после перезапуска.

## 7. Документация

- [ ] `docs/BETA_CHECKLIST.md` актуален.
- [ ] `docs/CHANGELOG.md` обновлён под текущую версию.
- [ ] `README.md` не противоречит текущему beta scope.
- [ ] Документы явно отмечают, если APK в этом изменении не собирался.
- [ ] Известные ограничения beta-билда понятны тестерам.

## 8. Сборка APK/AAB

Этот раздел пропускается для коммитов, где APK/AAB не собирается.

- [ ] Сборка выполняется из актуальной ветки.
- [ ] Export preset выбран правильно.
- [ ] Имя файла содержит версию билда.
- [ ] APK/AAB собирается без критических ошибок.
- [ ] Подпись APK/AAB проверена, если используется release-сборка.
- [ ] Финальный файл не лежит в Git как tracked-файл.

## 9. Перед отправкой тестерам

- [ ] Проверен последний запуск собранного билда.
- [ ] Версия в системном меню совпадает с именем файла.
- [ ] Тестерам передан `docs/BETA_CHECKLIST.md`.
- [ ] Тестерам объяснено, что основной водоём beta — Озеро Агамим.
- [ ] Тестерам объяснено, как пользоваться кнопкой “Сообщить о баге”.
- [ ] В changelog записано, что именно нужно перепроверить.

## Blocker перед отправкой

Билд нельзя отправлять тестерам, если:

- есть `SCRIPT ERROR`;
- не запускается Main-сцена;
- не работает сохранение;
- нельзя начать ловлю;
- нельзя закрыть основные модальные окна;
- системное меню не показывает версию;
- собран не тот commit или не та версия.
